# রিপন ম্যানেজমেন্ট — অফলাইন স্টক ও POS (GitHub থেকে চলা অ্যাপ)

ইন্টারনেট ছাড়াই চলে; ইন্টারনেট এলে সব কাজ নিজে নিজে **Google Sheets ও Drive**-এ সিঙ্ক হয়।
আগের Apps Script-এর **সব ফাংশন অক্ষত** — অফলাইনে ব্রাউজারের ভেতরে ঠিক সেই একই `Code.gs` চলে।

```
 ফোন / কম্পিউটার (PWA, github.io থেকে)                         Google
┌─────────────────────────────────────────────┐              ┌──────────────────────┐
│ Index UI ─▶ engine.js ─▶ Code.gs (অপরিবর্তিত)│   ইন্টারনেট   │ Apps Script Web App  │
│                │            ▲                │  ───────────▶ │  Api.gs ─▶ Code.gs   │
│                ▼            │ gas-shim.js    │   (সিঙ্ক)     │      │               │
│   IndexedDB (স্থানীয় ডাটা + জমা থাকা কাজ)      │  ◀─────────── │      ▼               │
└─────────────────────────────────────────────┘              │  Google Sheets+Drive │
                                                              └──────────────────────┘
```

## ফোল্ডার

| পথ | কী |
|---|---|
| `apps-script/Code.gs` | আগের ব্যাকএন্ড। **শুধু ৭ লাইন যোগ হয়েছে** (`setClock_`) — বাকি সব হুবহু আগের মতো |
| `apps-script/Api.gs` | **নতুন** — অফলাইন অ্যাপের জন্য JSON API (`doPost`), API Key, সিঙ্ক |
| `apps-script/Barcode.gs` | **নতুন** — প্রতিটি প্রোডাক্টের বারকোড PNG ছবি বানায় (Code.gs এটাই ব্যবহার করে) |
| `apps-script/Index.html` | আগের Apps Script ওয়েব অ্যাপ UI — অপরিবর্তিত (চাইলে আগের মতোই ব্যবহার করতে পারবেন) |
| `web/` | অফলাইন অ্যাপ (PWA): `index.html`, `js/engine.js`, `js/gas-shim.js`, `sw.js`, `manifest`, আইকন |
| `build.mjs` | `dist/` বানায় (ফন্ট লোকাল, Service Worker-এ ফাইল তালিকা) |
| `.github/workflows/pages.yml` | GitHub Actions: টেস্ট → বিল্ড → GitHub Pages-এ ডিপ্লয় |
| `tests/` | ব্যাকএন্ড ও অফলাইন-সিঙ্কের অটো টেস্ট |
| `twa/` | Android APK প্রজেক্ট (Bubblewrap) — প্রথমবার নিজের কম্পিউটারে বানাতে হয়, দেখুন `twa/README.md` |
| `.github/workflows/android.yml` | GitHub Actions: `twa/` থাকলে সাইন করা APK বিল্ড করে |

## ধাপ ১ — Apps Script (একবার)

1. আপনার আগের Apps Script প্রজেক্ট খুলুন। `Code.gs`-এর লেখা মুছে **এই রিপোর `apps-script/Code.gs`** বসান
   (আগের ফাংশন সব আছে; শুধু `setClock_` যোগ হয়েছে — অফলাইনে করা বিক্রি সার্ভারে **আসল তারিখ-সময়েই** বসাতে লাগে)।
2. নতুন ফাইল যোগ করুন (＋ → Script) নাম `Api`, তার ভেতরে `apps-script/Api.gs` বসান।
   আরেকটি নতুন ফাইল নাম `Barcode`, তার ভেতরে `apps-script/Barcode.gs` বসান (Code.gs এটা দিয়েই প্রতিটি প্রোডাক্টের
   আলাদা বারকোড ছবি বানায়)।
3. এডিটরে ফাংশন বেছে **`generateApiKey`** Run করুন → **Execution log**-এ আপনার গোপন **API Key** দেখা যাবে, কপি করে রাখুন।
   (পরে বদলাতে চাইলে আবার Run করুন, বা Project Settings → Script properties → `API_KEY`।)
4. **Deploy → Manage deployments → Edit → New version** (নতুন হলে New deployment → Web app):
   - Execute as: **Me**
   - Who has access: **Anyone**  ← github.io থেকে ডাকার জন্য দরকার; নিরাপত্তা দেয় API Key
5. **Web app URL** কপি করুন (`https://script.google.com/macros/s/…/exec`)।

## ধাপ ২ — GitHub

1. GitHub-এ নতুন রিপো বানান (যেমন `ripon-offline`) এবং এই ফোল্ডারের সব ফাইল আপলোড/পুশ করুন (`main` ব্র্যাঞ্চে)।
2. রিপোর **Settings → Pages → Build and deployment → Source: GitHub Actions** বেছে নিন।
3. **Actions** ট্যাবে “Build & Deploy” সফল হলে অ্যাপের ঠিকানা পাবেন:
   `https://<আপনার-ইউজারনেম>.github.io/<রিপো-নাম>/`
4. Actions-এর Artifacts-এ `ripon-offline-app` নামে বিল্ডের কপিও ডাউনলোড করা যায়।

## ধাপ ৩ — ফোন/কম্পিউটারে চালু

1. ঠিকানাটি খুলুন → প্রথমবার **Web app URL + API Key** বসান → “সংযোগ করুন ও ডাটা নামান”। (**প্রথমবার ইন্টারনেট লাগবে**)
2. **ইনস্টল করুন**: Chrome/Edge-এ “Install app” (বা সেটিংস পেজের বাটন)। iPhone: Safari → Share → **Add to Home Screen**।
3. এরপর ইন্টারনেট ছাড়াই খুলবে, বিক্রি/স্টক/খরচ/সঞ্চয় সব চলবে।
4. সার্চ বক্সের পাশের 📷 বাটনে ক্যামেরা দিয়ে বারকোড স্ক্যান করে প্রোডাক্ট খোঁজা/বিক্রি করা যায়; সেটিংস পেজ থেকে
   সব প্রোডাক্টের বারকোড ছবি ZIP করে ডাউনলোড করা যায় (অফলাইনেও), বা Google Sheet-এ বারকোড ছবি বানানো যায়
   (ইন্টারনেট লাগবে)।

## কীভাবে অফলাইন সিঙ্ক কাজ করে

- সব কাজ প্রথমে **এই ডিভাইসেই** হয় (একই `Code.gs` ফাংশন), তাই অফলাইনেও ফলাফল সঙ্গে সঙ্গে দেখা যায়।
- ডাটা বদলায় এমন প্রতিটি কাজ (বিক্রি, প্রোডাক্ট, স্টক, খরচ, সঞ্চয়, সেটিংস) **সারিতে** জমা হয়। বাম মেনু/উপরের ডট-এ দেখা যায়: 🟢 সিঙ্ক হয়েছে · 🟡 অপেক্ষায় · ⚪ অফলাইন · 🔴 সমস্যা।
- ইন্টারনেট এলে (এবং প্রতি ~৯০ সেকেন্ডে, অ্যাপ খুললে) কাজগুলো **ক্রমানুসারে সার্ভারে** চলে, তারপর Google Sheet-এর সর্বশেষ ডাটা নেমে আসে।
- **একই কাজ দুইবার হয় না** (প্রতিটি কাজের আলাদা আইডি; সার্ভারে `SyncOps` শীটে রেকর্ড থাকে)।
- **তারিখ/সময়** অফলাইনে করার সময়টাই থাকে (সিঙ্কের সময় নয়)।
- **একাধিক ডিভাইস**: দুই ডিভাইসে একই আইডির নতুন প্রোডাক্ট তৈরি হলে সার্ভার নতুন আইডি দেয় এবং সেই প্রোডাক্টের পরের কাজগুলোও ঠিক আইডিতে বসে।
- **সংঘর্ষ**: যেমন অন্য ডিভাইস আগে স্টক বিক্রি করে ফেলেছে — এমন কাজ হারায় না; **“সিঙ্ক হয়নি এমন কাজ”** তালিকায় কারণসহ থাকে (আবার চেষ্টা / বাদ দিন)। স্থানীয় ডাটা সব সময় Google Sheet-এর সত্যের সাথে মিলিয়ে নেওয়া হয়।
- **ছবি**: অফলাইনে তোলা ছবি ডিভাইসে থাকে, সিঙ্কে Drive-এ যায়; Drive-এর ছবিগুলো অফলাইনে দেখার জন্য ডিভাইসে নামিয়ে রাখা হয়।

## সতর্কতা

- **API Key গোপন রাখুন।** এটি রিপোতে লিখবেন না — অ্যাপে একবার বসান (ব্রাউজারেই থাকে)। Key ফাঁস হলে `generateApiKey` আবার Run করুন।
- সিঙ্ক না হওয়া কাজ থাকা অবস্থায় “Clear site data / ব্রাউজার ডাটা মুছুন” করলে সেই কাজগুলো হারাবে। আগে সিঙ্ক শেষ করুন।
- অ্যাপ ইনস্টল করে ব্যবহার করুন (বিশেষ করে iPhone-এ) — নইলে ব্রাউজার অনেকদিন না খুললে ডাটা মুছে ফেলতে পারে।
- একই ডিভাইসে একসাথে দুইটি ট্যাবে অ্যাপ খুলবেন না।
- **Code.gs বদলালে** `apps-script/Code.gs` ঠিক রেখে (১) Apps Script-এ নতুন ভার্সন ডিপ্লয়, (২) রিপোতে পুশ — দুটোই করুন, যাতে ডিভাইস ও সার্ভারে একই লজিক থাকে।

## অ্যান্ড্রয়েড APK

অ্যাপটি PWA — Chrome থেকে “Install” করলেই হোম স্ক্রিনে অ্যাপের মতো চলে; বেশিরভাগ ব্যবহারকারীর জন্য এটাই যথেষ্ট।

সত্যিকারের APK ফাইল (সাইডলোড করার জন্য) চাইলে **`.github/workflows/android.yml`** GitHub-এই সেটা বানিয়ে দেয়
(Google-এর Bubblewrap দিয়ে) — প্রথমবার নিজের কম্পিউটারে একটু সেটআপ লাগে (সাইনিং-কি বানাতে), এরপর থেকে GitHub
Actions নিজে থেকেই নতুন APK বানাবে। ধাপে ধাপে **`twa/README.md`** দেখুন।
বিকল্প হিসেবে GitHub Pages-এর ঠিকানাটি [PWABuilder.com](https://www.pwabuilder.com)-এ দিয়েও Android প্যাকেজ বানানো যায়।
